MGS2 - Arsenal Gear / Manhattan Crash
=====================================

Copy the contents of this folder into your MGS2 Master Collection install
(the folder containing METAL GEAR SOLID2.exe), keeping the folder structure.

Requires MGSHDFix (any current build).

NOTHING VANILLA IS OVERWRITTEN. The whole mod lives in the update folder, which
the ASI loader reads in place of the original paths. Not one of the game's own
files is added to, replaced or edited.

UNINSTALLING
------------
Delete the files listed in FILES.txt. If nothing else lives in the update
folder, deleting the folder does the same.

A Steam file verification will not remove or fight any of it.

Covers both the US/EU and Japanese releases; each loads only its own files.
