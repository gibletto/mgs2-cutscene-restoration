American Flag Restoration
Metal Gear Solid 2, Master Collection


Restores the American flag to the Federal Hall scenes:

  Flying on the pole
  Falling onto Solidus after Raiden cuts the pole
  The officer dragging it away
  Eleven flags on the street poles, and their sway

Covers the three ending cutscenes, the five Federal Hall cutscenes before them,
and the playable Solidus fight.


REQUIRES

  MGSHDFix (it brings the Ultimate ASI Loader, whose "update" overlay folder this
  installs into, and it merges the supplementary asset lists this adds)


INSTALL

  Copy the "update" folder into your MGS2 folder, next to METAL GEAR SOLID2.exe.
  If an "update" folder is already there, merge them.


UNINSTALL

  Delete the files listed in FILES.txt. Do not delete the whole update folder
  unless nothing else is using it.


CREDITS

  Flag positions along the street were measured from the MoreFlags / 911Restore
  mod, which first put flags back on those poles.
